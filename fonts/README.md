# CommitMono

The bundled OTF files are unmodified CommitMono 1.143 from the official release distributed by Homebrew's `font-commit-mono` cask.

- Website: https://commitmono.com/
- Upstream: https://github.com/eigilnikolajsen/commit-mono
- Family name: `CommitMono`
- Selected size: 14 pt
- Styles: 400 regular, 400 italic, 700 regular, 700 italic
- Licence: [SIL OFL 1.1](CommitMono/OFL.txt)
- Release customisation settings: [custom-settings.json](CommitMono/custom-settings.json)
- Integrity: [SHA256SUMS](CommitMono/SHA256SUMS)

The upstream font binaries retain their embedded attribution. They are not covered by any licence applying to original repository code.
